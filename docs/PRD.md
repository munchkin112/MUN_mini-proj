# 한강로컬패스 One-Pager

## 01 문제 정의
고객  여의도 출발 3시간 관광객
사실  운항 시간표와 시장 정보 출처 분리
가설  정보 확인과 이동 가능성 판단 부담  사용자 검증 전
기존 지도 한계  배 시간과 체류 예산 통합 검증 미확인

## 02 해결책
입력  출발 시각  3시간  식비 3만원  혼잡 회피
결과  배편  도보  시장  식사 순서별 시각과 출처
차별  공식 예정 시간표와 도보 경로 기반 충돌 검사
혼잡 회피 미지원 표시  실시간 운항과 영업 보장 제외

## 03 핵심 기능
P0 운항  날짜와 선착장 → 유효 시간표  출처  확인 시각
P0 장소  하선 선착장 → 시장과 가격 확인 식당  주소  가격
P0 일정  시간  식비  선호 → 배편 포함 후보  1건 이상 또는 불가 사유
P0 검증  후보와 경로 → 배 출발 전 도착  총시간과 식비 이내 판정
P0 복구  조회 실패 → 제한 재시도  유효 캐시 또는 실패 안내
완료  검증 통과 일정만 표시  근거 누락 시 불가 처리
P1 문화행사  지정 지역 현재 혼잡도  자동 운항 변경 반영

## 04 데이터와 AI
시장  음식 가격  공식 예정 시간표  보행 경로 확보 필수
API 공개와 인증  갱신  사용 조건  호출 검증은 docs/API_EVIDENCE.md
Planner  조건과 도구 결과 → 일정 후보  선호 해석에 LLM 사용
Executor  날짜와 좌표 → 실제 조회 결과  출처  시각
Validator  후보와 조회 결과 → Python 시간  가격  충돌 판정
Recovery  오류와 캐시 시각 → 재시도 또는 유효 캐시  실패 결과
전달  조건 → 조회 JSON → 후보 JSON → 검증 JSON → 화면

## 05 실행 계획
기술  FastAPI  React Vite  PostgreSQL  Docker  GitHub
1일차  A 데이터 권리와 호출 검증  B DB API  C 입력 화면  D 도구 계약
2일차  A 데이터 연결  B 시간 검증  C 결과 화면  D Planner 연결
3일차  A 장애 검증  B pytest  C 통합 배포  D 시나리오 검증
선행  1일차 실제 데이터와 경로 확보 → 2일차 일정 생성
완료  여의도 실데이터 일정 1건 검증  실패 시 불가 안내

## 06 위험과 결정
운항 자료 권리와 변경  사용 허가 확인  미확보 시 일정 생성 중단
경로와 가격 누락  확인된 장소만 사용  부족 시 불가 안내
API 장애와 환각  재시도 후 유효 캐시  검증 실패 결과 폐기
지표  조회 성공률  유효 일정률  검증 통과율  복구율  평균 응답시간
측정 정의와 목표  docs/API_EVIDENCE.md  현재 실측 없음
판단  No-Go  시간표 사용 권리  실제 API 호출  경로와 가격 확보 후 재판단
3일 가능성  선행 조건 충족 시 제한 구간 MVP 가능  실시간 기능 제외

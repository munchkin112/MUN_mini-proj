## 계약과 완료 판정

입력은 출발일과 시각 출발 선착장 총 이용시간 식비 선호  
최초 범위는 여의도 출발 배편 1회와 시장 1곳 식사 1곳 도보 이동  
공식 예정 시간표와 확인 시각을 노출하고 실시간 운항 여부는 공식 채널 재확인 안내  
제공 가능한 실제 식당 가격이 없거나 장소 영업 여부가 확인되지 않으면 해당 사실 표시  
식비 검사는 확보한 메뉴 가격 합계 기준이며 현장 가격 보장 아님  
시장과 식당의 영업시간이 확인되지 않으면 확정 가능 일정으로 판정하지 않고 사용자 확인 필요로 안내  
각 도보 구간은 경로 API 소요시간과 안전 여유시간을 합산  
안전 여유시간은 구현 전 팀이 정한 값과 근거를 기록하며 이동시간 보장으로 표현하지 않음  
배 출발 전 도착과 시간 범위 및 식비 기준을 모두 충족한 일정만 검증 통과  
확인 불가 항목이나 통과 후보가 없으면 근거와 함께 일정 생성 불가 안내  
캐시는 출처와 취득 시각 및 유효기간을 표시하고 시간표와 가격의 유효기간은 데이터 소유자의 갱신 정책과 변경 공지 확인 후 결정  
유효기간이 미정이거나 초과한 캐시는 검증 통과 근거로 사용 금지  
호출 오류 시 제한 재시도 후 유효 캐시만 사용하고 없으면 불가 안내  
복구 성공은 별도 재조회 또는 유효 캐시 검증에 성공한 경우로 제한  

도구 계약  schedule 날짜 선착장 → 적용기간 요일 출발 및 도착 선착장 출발 및 도착시각 출처 취득시각  
도구 계약  places 선착장 좌표 → 시장 식당 식별자 주소 가격 영업시간 휴무 적용기간 출처 확인시각  
도구 계약  route 출발좌표 도착좌표 → 도보 소요시간 출처 취득시각  
Planner는 Executor 도구의 실제 결과만 사용하여 장소 식별자와 순서 및 체류시간을 제안  
Validator는 Python에서 식별자 존재 여부와 모든 필수 데이터 시간 예산 충돌을 확인  
Recovery는 호출 실패 유형과 유효 캐시 여부를 규칙으로 판정  
도구 응답 누락과 LLM이 만든 임의 식별자는 실패로 처리

## 착수 판정

Day 1 종료 전 선착장과 적용 시간표의 확보와 가공 권리 확인  
시장과 식당 가격의 연결 및 실제 호출 확인  
도보 경로 API 키 발급과 대상 구간 호출 확인  
대상 장소 영업시간의 신뢰 가능한 확보 여부 확인  
LLM 도구 호출 계정과 배포 환경 확보  
필수 항목 중 하나라도 실패하면 실시간 운항이나 실행 가능 일정 보장을 주장하지 않고 No-Go 유지  
Day 3 완료 조건은 여의도 출발 3시간 식비 3만원 시나리오에서 실제 배편 시장 식당을 포함한 검증 통과 일정 1건  
데이터 부재와 장애 시 불가 안내는 별도 수용 조건이며 성공 일정 시연을 대체하지 않음
